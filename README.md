## What is DEXR?

**DEXR** is a local-first AI workspace that combines a deterministic execution core, a bounded recursive agent mesh, approval-gated tools, versioned project state and verifiable source reproduction.

Its central principle is simple:

> **A result is not accepted merely because it was produced. It must pass the required verification gates.**

DEXR is designed so that projects, logs, reports, manifests, state snapshots and generated artifacts remain on the user’s machine.
