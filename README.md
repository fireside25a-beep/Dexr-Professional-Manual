## What is DEXR?

**DEXR** is a local-first AI workspace that combines a deterministic execution core, a bounded recursive agent mesh, approval-gated tools, versioned project state and a verifiable self-reproduction system.

The application is designed around one central rule:

> **A result is not accepted merely because it was produced. It must pass the required verification gates.**

DEXR can operate without a cloud service, external account or required network connection. Its optional local model runtime communicates only through the local loopback interface.
